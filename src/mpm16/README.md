# mpm16

> Work in progress!

A 3D Material Point Method (MPM) simulator implemented in Python using the Nvidia Warp library, and following the implementation of [^1].

[^1]: C. Jiang, C. Schroeder, J. Teran, A. Stomakhin, and A. Selle, “The material point method for simulating continuum materials,” in ACM SIGGRAPH 2016 Courses, Anaheim, California: Association for Computing Machinery, 2016. doi: 10.1145/2897826.2927348.
